# Threats-Vs-Vulnerabilities
Modern cybersecurity focuses on identifying malicious actors aiming to breach systems alongside patching underlying system weaknesses before incidents occur. Businesses prioritize monitoring these distinct risk factors to safeguard operations and protect sensitive data.


| **Characteristic** | **Threat** | **Vulnerability** |
| :--- | :--- | :--- |
| **Definition** | Any potential danger or event that can harm an asset or system. | A weakness, flaw, or gap in a system's security that can be exploited. |
| **Source** | **External or internal force** (e.g., hackers, malware, natural disasters). | **Internal flaw** (e.g., outdated software, weak passwords, misconfigurations). |
| **Control** | You cannot control threats; you can only prepare for them. | You can actively control, patch, and fix vulnerabilities. |
| **Action** | **Exploits** a weakness. | **Is exploited** by a threat. |
| **Examples** | Ransomware, phishing, severe storms, disgruntled employees. | Open ports, unpatched bugs, lack of encryption, untrained staff. |
